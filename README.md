# わたしの暮らしTODO

iPhone のホーム画面から使う、個人用の TODO 管理 Web アプリ（PWA）です。

- データはすべて端末内（IndexedDB）に保存します。サーバーには送信しません。
- このリポジトリには、アプリのプログラムだけが入っています（タスクの内容は含みません）。
- ビルド不要の静的ファイル（HTML / CSS / JavaScript モジュール）です。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` / `css/app.css` | 画面 |
| `js/main.js` | 画面の表示と操作 |
| `js/state.js` | タスク・履歴・重点・分類の操作 |
| `js/recur.js` | 繰り返しの計算 |
| `js/importer.js` | 取り込み（Todoist CSV・取り込み用 JSON）、バックアップ形式 |
| `js/db.js` | 端末内保存と自動控え |
| `sw.js` / `manifest.webmanifest` | オフライン起動・ホーム画面追加 |

## 繰り返しのルール

- 毎日・曜日指定：やれなかった日は積み上げず、今日以降の次の実施日へ自動で進む
- 毎月・間隔・単発：予定日を過ぎたら「期限切れ」として残し、本人が「次の予定日／別の日／スキップ／見直し」から選ぶ
- 毎月 29〜31 日：その日が無い月は月末に実施し、翌月以降は元の日付に戻る
- 遅れて完了した場合、次回は「予定日より後で、今日以降の最初の実施日」（過去の回を重複生成しない）

## テスト

```
npm test
```

## 更新の公開
